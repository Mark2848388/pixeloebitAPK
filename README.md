# Pixel Orbit — Godot 4.3

Пиксельный космический шутер на **Godot** (не Flutter).

## Что есть
- Меню: кампания, классика, endless, арена
- Герои (Рекс / Нова / Болт / Эгида / Тень) — смена в меню
- Рывок и ульта (кнопки + Space / E на ПК)
- Волны, босс с 3 фазами, лут
- Сохранение монет / рекорда / прогресса кампании

## Управление
- Палец / мышь — движение
- **РЫВОК** / **УЛЬТА** — кнопки на экране

## Сборка APK
1. Залей папку на GitHub
2. Actions → **Build Godot APK**
3. Artifact `pixelorbit-godot-apk`

Локально (ПК с Godot 4.3):
```
Godot → Project → Export → Android
```

## Примечание
Первый CI-прогон Godot+Android иногда требует подправки export_presets / SDK path.
