# Pixel Orbit Flutter v1.1

## Что внутри
- Классика + Endless
- Магазин скинов
- Сезонный пропуск
- Онлайн-рейтинг (Supabase)
- Рейд-боссы каждые 3 волны: предупреждение на экране, усиленное HP и бонус 450 очков за победу
- Рейдовые предупреждения (внутриигровые, не системные push-уведомления)
- Иконка: пиксельный инопланетянин (`assets/icon-512.png`)

## APK
Залей репозиторий → Actions → artifact `pixelorbit-apk`.

## Supabase (один раз)
В SQL Editor проекта выполни файл `supabase_scores.sql`.
Ключи уже прописаны в `lib/online.dart` (тот же проект, что веб-версия).
