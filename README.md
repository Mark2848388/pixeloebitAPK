# Pixel Orbit (Flutter v1)

Пиксельный космический шутер — первая версия на Flutter.

## Что есть
- Пиксельная графика (корабль, враги, босс, HUD)
- Режим полёта: волны врагов, стрельба, жизни, счёт
- Меню в 16-bit стиле
- Сезонный пропуск (локальный прогресс, 20 уровней)
- Сохранение монет / XP / уровня пропуска

## Сборка APK (только телефон)
1. Залей папку в GitHub-репозиторий
2. Actions → **Build APK**
3. Artifacts → `pixelorbit-apk` → установи APK

```bash
# с ПК
flutter pub get
flutter run
```
