# Pixel Orbit v2

Офлайн APK (без Supabase — стабильная сборка).

## Фичи
- Пиксельное главное меню
- 5 героев со спрайтами, рывком, ультой, оружием
- Босс с 3 фазами
- Лут (монеты/гемы/scrap), ангар прокачки
- Кампания 10 миров, Endless, Арена (AI)
- База, сундуки, ивенты, друзья (локально)

## Управление
- Палец — движение
- Кнопки УЛЬТА / РЫВОК (или double-tap = рывок)

## Сборка
GitHub Actions → artifact `pixelorbit-apk`
